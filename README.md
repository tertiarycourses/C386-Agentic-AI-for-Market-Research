## Lab Activities

**Lab 1 — Build the LinkedIn Strategy, Profile, and Agent Boundary Map** · Connect the business result, audience evidence, profile value, tool roles, risk tiers, and human approval gates.

**Lab 2 — Write and Boundary-Test the LinkedIn G-C-A-T-E Prompt Contract** · Create a reusable instruction with grounded evidence, output checks, permissions, stop conditions, and adversarial tests.

**Lab 3 — Create the LinkedIn Voice, Profile, and Multi-Format Content Kit** · Produce a voice fingerprint, reviewed profile drafts, four posts, an article outline, and a six-page carousel brief.

**Lab 4 — Build the Fourteen-Day Content Calendar and Draft-First Workflow** · Sequence the content kit by audience need and move each item through source, drafting, review, and human scheduling states.

**Lab 5 — Build the Evidence-Based Prospect Segmentation Queue** · Apply transparent fit, evidence, relationship, timing, and risk rules to authorised synthetic records without scraping.

**Lab 6 — Draft the Personalised Connection and Nurture Sequence** · Create concise, relevant drafts with evidence maps, etiquette checks, bounded follow-up, stop rules, and human sending authority.

**Lab 7 — Design the Governed Content and Engagement Operations Workflow** · Connect content, comments, and follow-up through explicit states, role permissions, approval packets, exceptions, and trace records.

**Lab 8 — Diagnose Performance and Propose One Bounded Scaling Experiment** · Validate synthetic analytics, calculate defined metrics, diagnose the decision chain, and recommend one controlled improvement with rollback.

## About

This repository contains the complete courseware and connected lab materials for **Agentic AI for Linkedin Marketing** (**C386**) by Tertiary Courses / Tertiary Infotech. The learning journey progresses from LinkedIn strategy, personal brand, and prompting to content systems, prospecting, outreach, governed operations, analytics, and responsible scale.

All eight labs use the synthetic **Northstar Advisory** scenario. Learners build one `C386-linkedin-pack` across the course, so each reviewed output becomes an input to the next activity. Profile edits, public posts, invitations, messages, account changes, and other external actions remain behind explicit human approval gates.

The course teaches internal preparation and recommendation workflows. It does not teach scraping, unauthorised bots or browser extensions, mass messaging, inauthentic engagement, credential sharing, or automatic LinkedIn action.

| # | Activity | Concepts |
|---|----------|----------|
| **1** | **Strategy, Profile, and Boundaries** | Decision chain, audience evidence, profile value stack, tool roles, risk tiers, approval gates |

| **3** | **Voice and Content Kit** | Authentic voice, profile copy, hooks, posts, articles, document carousels, evidence and rights checks |

| **6** | **Outreach and Nurture Drafts** | Relevance ladder, invitations, post-acceptance value, etiquette, stop conditions, escalation |
| **7** | **Governed Operations** | Workflow states, separation of duties, engagement routing, exceptions, traceability |
| **8** | **Measurement and Improvement** | Metric definitions, data validation, funnel diagnosis, controlled experiment, cooldown and rollback |

## Getting Started

### Prerequisites

- An organisation-approved generative AI assistant
- A text or Markdown editor
- A spreadsheet application for CSV and metric work
- Access to the files in this repository
- Optional view-only access to your own LinkedIn interface for orientation

No scraping tool, browser automation, live posting, invitation sending, message sending, or account change is required.

### 1. Clone the repository

```bash
git clone https://github.com/tertiarycourses/C386-Agentic-AI-for-Linkedin-Marketing.git
cd C386-Agentic-AI-for-Linkedin-Marketing
```

### 2. Start with the Learner Guide

Open **[LG-Agentic AI for Linkedin Marketing (C386).md](LG-Agentic%20AI%20for%20Linkedin%20Marketing%20%28C386%29.md)** for the course concepts, preparation guidance, and complete lab instructions.

### 3. Complete the connected labs in order

1. Read [`labs/README.md`](labs/README.md).
2. Create a working folder named `C386-linkedin-pack`.
3. Complete Labs 1 to 8 in sequence because each lab reuses reviewed outputs from earlier labs.
4. Use only the supplied synthetic resources unless your trainer explicitly approves another safe dataset.
5. Keep every source, approval, exception, test, and decision record in the campaign pack.
